# YouTube Shorts 自動メーカー

PC内の動画ファイルを選ぶと、次の処理を自動で行うWindows用アプリです。

1. PC内の動画ファイルを読み込み
2. Whisperでタイムスタンプ付き文字起こし
3. OpenRouterで選択したLLMが指定した数の見どころを選定
4. FFmpegで9:16の縦型動画を指定した本数だけ作成

画面上部のタブで「動画ファイル・Shorts」と「生配信編集」を切り替えられます。生配信編集では従来どおりYouTube URLを使用できます。
Shorts作成時に元動画を変更・削除することはありません。

## 最初の起動

1. `setup.bat` をダブルクリックします。
2. 初回だけPython、Deno、動画処理機能などを自動で準備します。数分かかる場合があります。
3. アプリが開いたら、「動画を選択」で元動画を選び、OpenRouter APIキーを入力します。
4. 「モデル一覧を更新」を押し、使いたいモデルを選びます。
5. 「今回の切り抜き指示」に、その動画で作りたいShortsの方向性を入力します（空欄でも使えます）。
6. 「作成本数」で1〜20本から選び、「Shortsを作成」を押します。

黒い画面が途中で閉じた場合は、同じフォルダーの `setup.log` に原因が保存されます。修正版ではエラー時に画面も閉じません。

2回目からは `start.bat` をダブルクリックするだけです。

OpenRouter APIキーは [OpenRouter Keys](https://openrouter.ai/settings/keys) で発行できます。モデルごとの利用料金はOpenRouter側で発生します。

## 動画ファイルからShortsを作る

1. 「動画ファイル・Shorts」タブを開きます。
2. 「動画を選択」を押して、PC内の元動画を選びます。
3. OpenRouter APIキーと使用モデルを確認します。
4. 必要に応じて「今回の切り抜き指示」と作成本数を変更します。
5. 「Shortsを作成」を押します。
6. 途中で止める場合は「キャンセル」を押します。

- 対応形式の目安: MP4、MOV、MKV、WebM、AVI、M4V、WMV、FLV、TS、MTS、M2TS
- 動画ファイルはYouTube字幕を使用せず、毎回Whisperで文字起こしします。
- 1本あたり原則15〜60秒で、60秒を超える区間は60秒に調整します。
- 出力は背景ぼかし付きの9:16縦型MP4です。
- 元動画のフルパスと毎回の切り抜き指示は、設定ファイルや出力レポートへ保存しません。
- キャンセルすると処理中の動画書き出しを停止し、作成途中の一時ファイルを削除します。AIへの通信中は、安全に停止できる地点まで少し待つことがあります。

## LLMモデルの選択

- `openrouter/auto`: 内容に合うモデルをOpenRouterが自動選択します。迷った場合はこれを使います。
- 「モデル一覧を更新」: 現在利用できるテキストモデルをOpenRouterから取得します。
- 一覧にないモデル: モデルID（例: `提供元/モデル名`）を入力欄へ直接入力できます。
- Claude、Gemini、GPT、DeepSeek、オープンモデルなど、OpenRouterで提供されるモデルを同じ画面から利用できます。
- JSON Schema非対応モデルを選んだ場合は、通常のJSON生成へ自動的に切り替わります。

## 毎回の切り抜き指示

「今回の切り抜き指示」へ、その動画だけに使いたい編集方針を自由に入力できます。

- `テンポ重視で、30秒前後にまとめる`
- `驚きの発言や意外な結論を優先する`
- `初心者にも分かりやすい場面を選ぶ`
- `商品のメリットが伝わる場面を中心にする`

空欄の場合は標準方針で、指定した本数を選びます。入力内容はその回のLLM選定にだけ使用し、設定ファイル・ログ・出力レポートには保存しません。

## 生配信編集

「生配信編集」タブでは、生配信の無言・待ち時間・重複・脱線などをAIが除き、見どころをつないだ1本の通常動画を作成します。元動画の縦横比を維持し、縦型には変換しません。

1. 生配信URLまたは終了済みの生配信アーカイブURLを入力します。
2. 「完成動画の長さ」を0.5〜30分で指定します。
3. 配信中のURLでは「配信中の取得時間」を1〜360分で指定します。
4. 必要に応じて「今回の編集指示」を入力します。
5. 唐突に始まらないよう「冒頭の挨拶を入れる」をオンにします（初期状態でオンです）。
6. 締めを最後まで入れたい場合は「締めを優先」をオンにします（初期状態でオンです）。
7. 「生配信の不要部分を除いて作成」を押します。
8. 途中で止める場合は「キャンセル」を押します。

- 配信中: 現在の配信位置から指定時間だけ取得し、Whisperで文字起こしして編集します。
- 終了済み配信: アーカイブ全体の字幕を確認し、字幕がなければWhisperを使用します。
- OpenRouter、モデル、Whisper精度、画質の設定は「動画ファイル・Shorts」タブの値を共通で使用します。
- 編集指示はその回だけLLMへ送り、設定ファイル・ログ・出力レポートには保存しません。
- 完成動画は指定した分数を目安にし、採用した区間は `編集内容.json` へ保存します。「締めを優先」をオフにすると指定時間で正確に終了します。
- 「締めを優先」がオンの場合は、最後の発言・結論・挨拶・余韻を途中で切らず、指定時間を少し超えることがあります。
- 「冒頭の挨拶を入れる」がオンの場合は、元配信の挨拶を検出して先頭へ入れます。挨拶がない場合は、AIが自然な導入から始まる区間を選びます。

## 出力先

完成した動画は、このフォルダー内の `outputs` に保存されます。各動画ごとに次の内容が入ります。

- `01_タイトル.mp4` 〜 選択した本数分のMP4
- `見どころ一覧.json`
- `文字起こし.txt`

生配信編集では、`生配信切り抜き_○分.mp4`、`編集内容.json`、`文字起こし.txt` が保存されます。

## 設定の目安

- Whisper精度: 普段は「標準（small）」がおすすめです。動画ファイルは毎回Whisperで文字起こしするため、長い動画や高精度設定ほど時間がかかります。
- 元動画ファイル: MP4、MOV、MKV、WebM、AVIなど、FFmpegで読み込める一般的な動画を選べます。選択したファイルの場所は設定や出力レポートへ保存しません。
- 動画サイズ: 最初は「720p（高速）」がおすすめです。
- 作成本数: 1〜20本から選べます。選んだ本数に合わせてAIの見どころ選定と動画の書き出しを行います。

## 注意

- 自分が権利を持つ動画、または編集・投稿の許可を得た動画だけを使用してください。
- YouTubeやOpenRouter側の仕様変更により、依存機能の更新が必要になる場合があります。その場合は `setup.bat` をもう一度実行してください。
- OpenRouter APIキーを保存する場合は、平文ファイルではなくWindows資格情報マネージャーへ保存されます。
- `%APPDATA%\YouTubeShortMaker\settings.json` にはモデル名など秘密ではない設定だけが保存されます。
- 旧バージョンで平文保存されていたAPIキーは、初回起動時にWindows資格情報マネージャーへ自動移行され、設定ファイルから削除されます。

## APIキーの流出防止

- `.env`、設定ファイル、ログ、仮想環境、生成動画は `.gitignore` でGitHub対象外です。
- コミット前フックとGitHub Actionsで、OpenRouter・GitHubなどのキー形式や秘密鍵を検査します。
- APIキーをログへ出力する処理はありません。

## 将来のLLM拡張

LLM接続は `llm_providers.py` に分離されています。動画ファイル入力・Whisper・切り抜き処理には手を入れず、`LLMProvider` を継承した接続クラスを追加して登録するだけで、別のLLMサービスを増やせる構成です。
